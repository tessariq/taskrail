## Revision Decision

Repository review prompts remain configurable only through versioned whole-file
replacement of fixed built-in IDs. Each prompt-produced leaf review artifact now
records the role-mandated prompt ID, contract version, exact pre-substitution
template digest, and effective `builtin|replacement` source. Publication resolves
and rechecks that tuple through active storage. The binding records publication-
time template resolution only: it does not prove prompt delivery or use, reviewer
identity or independence, provider identity, replacement safety, or semantic
quality.

Rendered-prompt digests and replacement paths remain absent from durable review
artifacts. Rendered text contains transient proposal paths that are not durable
review context, while task/spec/draft/trace/product digests already bind the
subjects. Manifests and workflow memory bind immutable leaf files by digest and do
not duplicate one prompt tuple across potentially different review roles or runs.

## Method

The review reconsidered the complete v0.5 feature spec, machine companion,
inherited v0.6 review schemas, current prompt/review task graph, local-storage
model, recovery boundary, and all v0.5 task files through four questions:

1. Consistency: can built-in and replacement review output make different claims
   under an indistinguishable durable schema?
2. Gaps: can producers obtain and publishers recheck the exact template
   resolution without a race or physical local path?
3. Additions: what smallest metadata and task outcome closes that gap without a
   general prompt framework or additional review state?
4. Adversarial: can a producer claim a built-in, repair stale metadata, bind an
   ephemeral rendered path, or turn resolution metadata into false attestation?

Two independent read-only review contexts then checked the normative contract and
task graph. Their findings were dispositioned and the revised files were reviewed
again with no remaining actionable issue.

## Finding Dispositions

| ID | Lens | Severity | Finding | Disposition and result |
|---|---|---:|---|---|
| C-009 | consistency | high | A review produced under arbitrary replacement guidance was durably indistinguishable from one using the built-in. | accepted: every prompt-produced leaf records role, v1 contract, exact template digest, and source class. |
| C-010 | consistency | medium | v0.6 task-review schema 2 retained immutable `task_path`, but only schema 1 received the archival scanner's historical-metadata exception. | accepted: both strict task-review schemas receive the same narrow top-level exception. |
| G-010 | gaps | high | `prompt render --json` exposed only rendered-content digest, so a producer could not atomically obtain the template digest from the same resolution. | accepted: prompt content results expose both returned-content and pre-substitution template digests. |
| G-011 | gaps | high | Prompt/configuration changes between validation and publication, including workflow recovery, lacked an exact final boundary. | accepted: exact config and prompt bytes are rechecked at the directory commit or workflow fence; fenced recovery uses the frozen candidate. |
| G-012 | gaps | medium | Existing prompt, schema, publisher, and review tasks did not own one end-to-end cross-type binding outcome without creating a renderer/publisher dependency cycle. | accepted: T-255 owns shared publication-time verification after T-215, T-240, and T-250; review producers and the workflow publisher consume it. |
| ADV-011 | adversarial | high | A rendered digest could bind durable evidence to transient proposal paths and still be misrepresented as proof that a reviewer followed the prompt. | accepted: durable artifacts bind template bytes only and explicitly disclaim delivery, identity, independence, and semantic certification. |
| ADV-012 | adversarial | medium | Adding, removing, or replacing an override with equal built-in bytes could silently change repository policy without staling an unpublished proposal. | accepted: source class is checked independently from exact-byte digest, with deterministic invalid/stale error precedence and no fallback. |

No addition finding justified arbitrary prompt IDs, composition, optional review
lenses, per-run prompt files, provider configuration, or prompt-use attestation.
Those remain outside v0.5.
